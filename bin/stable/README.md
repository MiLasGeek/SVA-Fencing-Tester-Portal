# Stabile OTA-Bundles

Dieser Ordner enthält freigegebene OTA-Bundles für den SVA-Fencing-Tester. Die jeweils aktuelle Version wird über `../version.json` referenziert.

Ältere, kompatible Versionen bleiben hier für einen möglichen Downgrade verfügbar. Verwende nur vollständige `.ota`-Bundles, die für die jeweilige Hardware-Revision freigegeben sind.

Eine Anleitung zum lokalen Update über die Geräte-Webapp findest du in der [Update-Anleitung](../README.md).
