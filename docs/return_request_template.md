# Vorlage Rücknahme eines Evaluierungskits

Diese Vorlage dient Vereinen zur Ankündigung einer Rückgabe. Bitte keine
Privatadresse, Telefonnummer oder andere sensible Daten in einem öffentlichen
GitHub-Issue veröffentlichen.

## Kontaktaufnahme

Vor einer Rückgabe bitte zunächst über das Projektportal oder die im Impressum
genannte Kontaktmöglichkeit melden. Die Rücknahme wird anschließend abgestimmt;
eine persönliche Übergabe ist der Regelfall.

## Angaben zur Rückgabe

- Verein:
- Ansprechpartner und Funktion im Verein:
- Kit- oder Gerätekennung, falls vorhanden:
- Grund der Rückgabe: Ende der Evaluation / Defekt / Projektabbruch / sonstiger
  Grund
- Zustand des Kits: vollständig / unvollständig / beschädigt
- Ist ein Akku angeschlossen? ja / nein
- Bei Beschädigung, Wärmeentwicklung oder aufgeblähtem Akku: Gerät nicht laden
  oder weiter betreiben; diesen Umstand vorab mitteilen.

## Ablauf

1. Rückgabe ankündigen und die Angaben oben übermitteln.
2. Rückgabeweg mit dem Projekt abstimmen.
3. Kit möglichst vollständig und ohne angeschlossenen, vom Verein selbst
   beschafften Akku übergeben.
4. Die weitere Prüfung, Wiederverwendung oder fachgerechte Entsorgung wird
   dokumentiert.

Die Vorlage beschreibt einen organisatorischen Rücknahmeweg. Sie ersetzt keine
gesetzlichen Rücknahme-, Transport- oder Entsorgungsvorgaben.
